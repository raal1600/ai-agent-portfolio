Problem and idea

Coding agents work fast, but without limits they commit, deploy or widen the scope on their own.

The idea: the agent can only act on a batch that a person authorized exactly. Work runs under a lease, an independent reviewer checks it, and the harness stops before anything that was not approved.

How it works

  1. PlanIdea, specification and tickets
  2. AuthorizeThe person approves one exact batch
  3. DeliverLeased implementation with checkpoints
  4. ReviewAn independent reviewer checks the work
  5. StopHard stop before anything unauthorized

What I built

  • An extension suite of about 8,500 lines: a control plane with capability gates, deterministic phase routing and resumable sessions.
  • Cross-process leases, bounded parallel agents and hard stops before commits, deployment, destructive actions or scope changes.
  • Obsidian knowledge tools with bounded retrieval, path controls and approved changes only.
