Problem and idea

Tailoring a CV and a letter for every application is slow, and generic AI writing invents experience the applicant does not have.

The idea: keep a knowledge base of saved CV variants, tailor only from that evidence, check the result, and export ready-to-send PDFs.

How it works

  1. Job postingPaste or upload the ad
  2. Find evidenceSearch saved CV variants
  3. TailorCV and personal cover letter
  4. CheckAdvisory ATS readiness review
  5. ExportBoth documents as PDFs

Readable transcript

Synthetic product concept. The recording illustrates intended behavior using a fabricated person, company, job, profile evidence, documents, and ATS score. The score is advisory—not an employer ATS result, hiring prediction, or guarantee. Open the visualization source.

What I built

  • A multi-user platform with authentication, private storage and ownership checks on every record.
  • Profile import with validation and a reviewed diff before anything is applied.
  • Consent controls for any data used to improve the product.
  • Document generation and PDF export.

Quality evidence

  • Each planned slice ships only after the type check, the test suites and a browser smoke test pass.

Current limits

  • The recording is a synthetic product concept with a fabricated person, company and job. It is not footage of a shipped interface.
  • The ATS score is advisory. It is not an employer’s result or a hiring prediction.
  • The source is private. I can arrange a supervised review.
