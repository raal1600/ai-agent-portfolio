Problem and idea

People who build PCs plan their parts in spreadsheets and share screenshots. There is no single place to plan a build, save it, and let others learn from it or start from it.

The idea: a build studio with running totals, a cloud workspace for saved builds, and a showcase where the community can browse and reuse them.

How it works

  1. Sign inAccounts with NextAuth
  2. Build studioPick components; totals for price and power update as you go
  3. SaveCloud workspace in PostgreSQL through Prisma
  4. ShareShowcase, tags and media
